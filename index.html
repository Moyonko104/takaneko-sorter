¿Cómo lo consigo? (una sola vez)
  1. Entrá a Google Cloud Console y creá un proyecto.
  2. En "APIs y servicios", activá YouTube Data API v3.
  3. En "Pantalla de consentimiento OAuth", elegí "Externo" y agregá tu mail como usuario de prueba.
  4. En "Credenciales", creá un ID de cliente OAuth de tipo "Aplicación web".
  5. En "Orígenes autorizados de JavaScript" poné la URL de tu GitHub Pages, por ejemplo https://tuusuario.github.io (y http://localhost:8000 si probás en tu compu).
  6. Copiá el Client ID y pegalo arriba.
